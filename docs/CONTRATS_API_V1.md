# Contrats API V1 — état implémenté localement

Extension proposée sur `fix/v1-quality-recovery` (MOC M02, revue en attente) : liste `/bulletins` enrichie des seuls champs d'identité figés année/postnom/matricule/cycle ; détail enrichi de `publicationComplete` et `documentPeriodSupported`. Le consommateur W25 les utilise pour filtrer et éviter un document incomplet/inadapté. Le gabarit courant devient DEMO-V1.6 ; V1.5 reste accessible si une émission historique existe. Aucun changement de permission ni migration. Voir [comparaison et stratégie](REPRISE_QUALITE_V1.md).

Préfixe `/api/v1`, JSON UTF-8. `/health` public minimal. Identifiants UUID ; dates civiles AAAA-MM-JJ, bornes inclusives sauf fin d'affectation exclusive ; décimaux transmis en chaînes. Cookie HttpOnly commun, aucun Bearer alternatif. Toute écriture exige Origin autorisée et `X-CSRF-Token` obtenu par GET `/auth/csrf` ; token uniquement en mémoire. Authentification et permissions restent vérifiées côté serveur pour les accès directs.

Statut : C01 suit la cible approuvée feuille09 ; C02–C09 ci-dessous sont des **identifiants de contrats intermodules proposés** à la MOC. Ils ne remplacent pas les identifiants C01–C09 des contrôles de sécurité feuille08 (mot de passe, identifiants, brute force, cookie, stockage session, expiration, CSRF, RBAC, ABAC). Ces nouvelles routes ne sont pas présumées approuvées par les propriétaires. Pas de DELETE exposé.

Extensions C07 de démonstration : GET/POST `/results/profiles` (lecture school.read, création ADM) ; GET `/results/snapshots/:id/deliberation`, POST `/results/snapshots/:id/decisions` (DIR) ; GET `/results/retake-authorizations` (ENS affecté). Profil `{code,version,schoolYearId,cycle,level,optionCode,status:'DEMO_PROPOSE',source,config:{admissionThreshold,failureThreshold,retakeMode}}`. Décision `{profileId,outcome,reason,courseIds}` ; append-only avant publication. Évaluation REPECHAGE porte `decisionId`. Tests deliberation et deuxième session réelle.

Exemple fictif de création d'évaluation : `{assignmentId:'<uuid>',classPeriodId:'<uuid>',title:'Travail DEMO',kind:'TRAVAIL_JOURNALIER',maxScore:'20',heldOn:'2025-09-02'}`. Les identifiants proviennent de bootstrap/mine, jamais d'un acteur choisi par le client. Exemple note zéro : `{version:1,grades:[{enrollmentId:'<uuid>',score:'0'}]}`. Vide : `score:null`, bloque la clôture ; ABSENT/DISPENSE sont distincts et ne valent pas0.

Erreurs communes : 400 format/domaine invalide ; 401 session absente/expirée/révoquée ; 403 permission/scope/CSRF/auto-décision ; 404 ressource introuvable ou non publiée ; 409 conflit de version/état/unicité/concurrence ; 429 limitation ; 503 indisponibilité sans stack ni détail SQL. Les erreurs de grille gardent les erreurs par inscription. Login inconnu et mot de passe erroné ont la même réponse. Les notes soumises ne sont pas modifiables par DIR.

Limites explicites : liste élèves paginée50 sans total, bulletins limités500, comptes paginés50 côté API. Aucune ouverture de session ELEVE dans cette livraison. Définir pagination complète de tous les sélecteurs pour établissement volumineux avant production.
